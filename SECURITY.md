## Security Policy

We take security seriously. If you believe you’ve found a vulnerability that impacts users, please contact the maintainers privately.

### Reporting
- Email: open an issue and request a maintainer contact, or redact sensitive details
- Please include steps to reproduce, affected versions, and platform

### Scope
- Desktop app (Tauri) and web app code within this repository
- Third‑party APIs/libraries are out of scope; report upstream if applicable

### Handling
- We will acknowledge within 7 days and aim to provide a fix or mitigation plan shortly after
